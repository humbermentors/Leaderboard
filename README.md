# Got Game? Gaming Competition Leaderboard

Live leaderboard for the FYE x Humber Esports "Got Game?" gaming competition at Lakeshore Campus.

- **Staff view:** open the page normally to add participants and score with the quick-score buttons.
- **TV view:** add `#tv` to the end of the link, or click **Show TV display**.

Scores are saved in the browser, so run the staff and TV views in the same browser on the same computer, and don't use a private or incognito window.
